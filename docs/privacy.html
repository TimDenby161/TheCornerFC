Privacy, corrections and security

Last updated 27 September 2026

Privacy

The Corner FC is a static website. It has no accounts, sign-up forms, cookies, advertising or analytics, and it doesn't collect or store anything about you on a server of its own.

  • Hosting. The site is served by GitHub Pages. Like any web host, GitHub receives your IP address and browser details when you load a page. See the GitHub General Privacy Statement.
  • Images from other sites. Club badges, player and manager photos and competition logos load directly from API-Football's image server (media.api-sports.io). Country flags load from flagcdn.com. Your browser contacts those servers, so they receive your IP address, browser details and the site's address (thecornerfc.com, not the page you're on). Their own privacy policies apply to those requests.
  • Settings kept in your browser. The paper bank and stake size you enter on Model vs Market, and whether to show players' seasons by year, are saved in your browser's local storage (fc.balance, fc.stakePct, fc.playerYears) so they're still there next time. They never leave your device. Clear them by clearing this site's data in your browser.

The site shows information about professional footballers and managers (names, clubs, ages, nationalities, match statistics, injuries and ratings computed from those). It comes from API-Football and the Fantasy Premier League game's public data. If something about you is wrong or you want it removed, use the corrections route below.

Corrections

If you spot a wrong result, player, club, injury or other data error, please open an issue on GitHub with the page address and what's wrong. Issues are public, so don't include anything private. Ratings, projections and probabilities are model output. They're estimates, not facts, and aren't betting advice. How the models work explains them and how accurate they've been.

Security

Please report security problems privately through GitHub's private vulnerability reporting, not in a public issue. The policy is in SECURITY.md, and security.txt has the same contact.
